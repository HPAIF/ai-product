# Inbox

Drop material here for the AI product manager: interview notes, call transcripts, survey exports,
support-ticket exports, analytics exports, sales notes, competitor documents. The `feedback-log`
skill files each item: feedback rows go to `ai-team/product/feedback.md`, raw interview notes move
to `discovery/notes/`, data exports feed `metrics.md`.

This folder may contain personal data — don't sync it to public places.
