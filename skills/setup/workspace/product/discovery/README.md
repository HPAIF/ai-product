# Discovery

- `OST-<product>.md` — the opportunity solution tree for each product (outcome → opportunities →
  solutions → assumption tests), from the plugin's `templates/opportunity-tree.md`. A living
  document: update it after every 3–4 interviews; record big changes in the journal.
- `DS-XXXX-short-slug.md` — synthesis of a batch of interviews, a survey or a ticket export
  (skill `discovery`, template `discovery-synthesis.md`).
- `IG-XXXX-short-slug.md` — interview guides (template `interview-guide.md`).
- `notes/` — raw interview notes and transcripts. **Personal data:** keep only what is needed,
  pseudonymise in everything outside this folder.
