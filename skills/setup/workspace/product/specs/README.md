# Specs and pitches

One file per spec or Shape Up pitch: `SPEC-XXXX-short-slug.md`, from the plugin's
`templates/spec.md` (skill `write-spec`). Front-matter `status` is read by the session hook:
draft → review → approved → building → shipped → measured, or parked / dropped.
Keep `updated:` current. Never delete a spec; mark it and link what replaced it.
