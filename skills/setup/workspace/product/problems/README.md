# Problem briefs

One file per problem or opportunity worth framing: `PB-XXXX-short-slug.md`, from the plugin's
`templates/problem-brief.md` (skill `problem-framing`). A brief comes before any spec.
Status in front-matter: framing / ready / parked / dropped / specced (link the SPEC).
Never delete a brief; mark it and link what replaced it.
